# Трекер книг

**list** (`books`) хранит все книги, потому что набор записей меняется. **tuple** `(id, название, автор, год)` описывает одну книгу: структура фиксирована, и запись нельзя случайно изменить. **dict** (`books_by_id`) нужен для быстрого поиска по id, а **set** (`authors`, `read_ids`) - там, где важна только уникальность. Наружу отдаётся копия списка, а изменяемых аргументов по умолчанию нет.
